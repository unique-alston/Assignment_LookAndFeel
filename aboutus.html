About the developer

Hi, I'm Unique, a student in ISM 6225 at the University of South Florida. I built Hemline as a static demo of a clothing store's inventory and sales tools. We feature a select amount of pieces that have gained a lot of traction on social media. We help our customers stay on top of current trends in the fashion space.

How I built it

I started from the course starter repository and planned four pages: home, inventory (mock CRUD), analytics, and this page. All pages share one stylesheet and the same top menu.

Technologies

HTML5, CSS3 (grid and flexbox, no framework), vanilla JavaScript, Chart.js for charts, and GitHub Pages for hosting.

What I learned

This was my first time building a website. The hardest part was learning GitHub, and I learned how HTML, CSS and JavaScript work together. With more time, I would add real product photos.
